# Reference Target tests

Tests in this directory are for the Reference Target feature for shadow DOM.

See https://github.com/whatwg/dom/pull/1353 and
https://github.com/whatwg/html/pull/10995 for the specification, and the
explainer at
https://github.com/WICG/webcomponents/blob/gh-pages/proposals/reference-target-explainer.md
for more information about the API.
