This file defines one top-level constant (credPropsTests) and an inline async test function (anonymous) that is created and invoked repeatedly; it also declares a few short-lived local variables inside the loops. Several helper/test functions are used but are not defined in this file (they come from helpers.js / testharness). Below is a concise inventory and short definition for each item. Top-level variables credPropsTests (const) An array of test-fixture objects. Each fixture contains: name: string describing the authenticator type. authenticatorArgs: object with virtual-authenticator configuration (protocol, hasResidentKey, hasUserVerification, isUserVerified, ...). expected: object with expectations for each resident-key requirement ("discouraged", "preferred", "required"). Each expectation contains fields like success, hasRk, and rk that describe expected outcomes for the credProps extension. Local variables (declared/used inside the loops / test function) fixture (const in for..of) Holds the current fixture object from credPropsTests for the outer loop iteration. rkRequirement (const in for..of) Holds the current residentKey requirement string ("discouraged", "preferred", or "required") for the inner loop. promise (const) The Promise returned by createCredential({...}) — represents the in-progress navigator.credentials.create() operation for the test. expected (const) The expectation object for the current fixture and rkRequirement (fixture.expected[rkRequirement]). cred (const) The resolved PublicKeyCredential returned by await promise when expected.success is true. credProps (const) The credProps extension result object obtained from cred.getClientExtensionResults().credProps. t (parameter) The test harness test object passed into the async callback (provided by virtualAuthenticatorPromiseTest). Function definitions in this file Anonymous async test callback (async t => { ... }) An inline async arrow function passed as the first argument to virtualAuthenticatorPromiseTest. Behavior: Calls createCredential(...) with authenticatorSelection.residentKey set to the current rkRequirement and extensions.credProps = true. If expected.success is false, asserts that the promise rejects with NotAllowedError via promise_rejects_dom. Otherwise awaits the promise, extracts credProps via cred.getClientExtensionResults(), and checks presence/value of rk according to expected.hasRk and expected.rk using assert_true / assert_equals.
